# Contributing Guidelines

Thanks for your interest in improving this repository.

## Ways to contribute
- Fix typos or improve clarity in documentation.
- Suggest better repository structure for long-term maintainability.
- Propose templates or workflows that improve consistency.

## Contribution process
1. Open an issue describing the change (for non-trivial updates).
2. Fork the repository and create a focused branch.
3. Keep changes small, clear, and scoped.
4. Open a pull request with a concise summary and rationale.

## Content expectations
- Keep notes concise and timestamped.
- Avoid adding sensitive or private information.
- Use respectful, inclusive language.

## Pull request checklist
- [ ] Change is scoped and clearly described
- [ ] Documentation is updated if needed
- [ ] No unrelated changes are included
