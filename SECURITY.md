# Security Policy

## Reporting a vulnerability
If you discover a security issue, please do **not** open a public issue.

Use GitHub private vulnerability reporting:
- https://github.com/SEPURI-SAI-KRISHNA/til-everything/security/advisories/new

If private reporting is unavailable, open a discussion first and request a private contact channel before sharing details.

When reporting, include:
- A clear description of the issue
- Steps to reproduce
- Potential impact
- Suggested remediation (if available)

## Response expectations
The maintainer will acknowledge reports and assess impact as quickly as possible.
