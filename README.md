# TIL Everything

A personal **Today I Learned (TIL)** repository for capturing short, timestamped notes from daily learning across technology and beyond.

## Why this repository exists
- Build a consistent habit of writing down key takeaways.
- Keep learning notes searchable and organized by date.
- Track progress over time with lightweight daily logs.

## Repository structure
- `/log/` — Daily markdown entries named as `YYYY-MM-DD.md`.

## How to add a new entry
1. Create or open today’s file in `/log` using the `YYYY-MM-DD.md` format.
2. Add bullet points with a timestamp and concise takeaway.
3. Keep entries factual, short, and useful for future reference.

### Recommended entry format
```md
- **HH:MM** — What you learned and why it matters.
```

## Scope
This repository is intentionally broad. Notes can include:
- Software engineering and tools
- Productivity and workflows
- General knowledge and life learnings
